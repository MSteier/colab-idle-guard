Colab Idle Guard

This extension reports activity kinds (click, key, scroll…) and cell-execution state from Google Colab tabs to the Colab Idle Guard app on this computer. It never sends what you type, notebook content, or anything from other websites.

Pairing

The token is stored only in this browser profile (chrome.storage.local) and is sent only to http://127.0.0.1 on the port above.
